# 상품성 검증

1. 판매가와 공급가를 분리해 기록한다.
2. 운송, 관세·부가세, 수수료, 포장·반품 비용을 총원가에 포함한다.
3. 보수·기준·낙관 시나리오로 손익을 계산한다.
4. 경쟁 상품의 가격·후기·약점을 비교한다.
5. 최소 테스트와 중단 기준을 제안한다.

추정값과 확인값을 구분하고 숫자의 출처 또는 계산식을 남긴다.
