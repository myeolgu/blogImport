# 수입·통관 검토

1. 용도, 소재, 전기·배터리 여부, 접촉 대상, HS 분류 후보를 확인한다.
2. 관련 인증·신고·표시·수입 제한 여부를 공식 기관 자료로 확인한다.
3. 관세·부가세·통관비와 필요한 서류를 목록화한다.
4. 확인되지 않은 규제 판단은 전문기관 확인 항목으로 표시한다.
5. 실행 전 필요한 서류와 승인 체크리스트를 제공한다.

규정은 변경될 수 있으므로 조사일, 관할 기관, 공식 출처 링크를 기록한다.
