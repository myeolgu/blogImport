# AI 도구 리뷰 작성

자세한 공통 편집 규칙은 [references/editorial-style.md](references/editorial-style.md)를 따른다.

- 첫 문장에서 도구의 핵심 용도와 추천 사용자를 설명한다.
- `What it does`, `Best for`, 가격, 장점, 단점을 서로 모순 없이 작성한다.
- 장점만 나열하지 말고 비용, 학습 난이도, 사용 제한, 대체재를 함께 설명한다.
- 확인하지 못한 기능을 단정하지 않는다.
- 제목은 도구명과 검색 의도를 포함한다. 예: `{도구명} Review and Pricing`.
- 리뷰는 제휴 링크가 없어도 독립적인 정보로 완결되어야 한다.
- 모든 리뷰는 같은 순서와 말투를 유지한다: 한줄 결론 → What it does → Best for → Pricing → Pros and cons → Limitations → Visit link.
- 기본 언어는 영어로 쓰고, 짧은 문장과 구체적인 동사를 사용한다.

사이트에 들어가는 평점은 임의로 조작하지 말고, 평가 기준과 출처를 내부 기록에 남긴다.
