# 제휴 수익화 운영

- `affiliateUrl`과 일반 공식 URL을 구분한다.
- 제휴 링크는 사용자가 도구를 이해하고 선택할 수 있는 문맥에 배치한다.
- 리뷰 페이지에는 제휴 수익 가능성을 명확히 고지한다.
- 과장된 수익·성능 보장을 피하고, 가격·기능은 공식 페이지에서 확인한다.
- 링크는 `target="_blank"`와 `rel="sponsored noreferrer"`를 사용한다.
- 링크가 없어도 페이지가 유용하도록 비교 정보와 대안을 제공한다.

새 제휴 프로그램을 연결할 때는 프로그램 조건, 대상 국가, 쿠키 기간, 커미션 기준, 브랜드 사용 제한을 기록한다.
