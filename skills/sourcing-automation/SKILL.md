# 소싱 자동화

1. 반복 작업의 입력·처리·출력·승인 지점을 정의한다.
2. 출처, 수집일, 상품 식별자, 통화, 단위를 표준화한다.
3. 조사 결과를 후보 데이터셋과 요약 리포트로 분리한다.
4. 실패·중복·가격 변경을 기록하고 재실행 가능하게 만든다.
5. 외부 영향이 있는 단계는 사용자 승인으로 멈춘다.

자동화 설계에는 데이터 스키마, 실행 주기, 예외 처리, 사람 확인 지점을 포함한다.
