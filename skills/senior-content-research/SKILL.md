# Senior Content Research

블로그와 스마트스토어가 하나의 문제 해결 흐름으로 연결되도록 조사한다.

## 조사 순서

1. 시니어 또는 보호자가 실제로 검색할 질문을 정한다.
2. 정부24, 보건복지부, 국민건강보험공단, 지자체, 제조사 등 1차 출처를 확인한다.
3. 무료 해결 방법과 상품이 필요한 상황을 구분한다.
4. 상품의 가격, 규격, 사용법, 배송, 교환·반품, 안전 주의사항을 확인한다.
5. 검색 키워드와 스마트스토어 상품명 후보를 함께 정리한다.

## 일일 트렌드 조사

한국·일본·미국·유럽의 시니어 건강, 운동, 생활 보조, 디지털 지원 주제를 비교한다. “해외에서 핫하다”는 표현은 최근 공식 자료, 검색·영상 반응, 반복 질문 등 근거를 2개 이상 확인했을 때만 사용한다. 결과는 `오늘의 트렌드 3개 → 운동 주제 1개 → 해외 벤치마킹 2개 → 글 제목 → 상품 기회` 순서로 정리한다.

건강·운동은 유행 영상만으로 효과를 판단하지 않고 공공기관 자료로 안전성을 검증한다.

## 결과 형식

질문 → 대상 독자 → 핵심 답변 → 단계별 해결법 → 상품이 필요한 조건 → 상품 비교 → 공식 출처 → 확인일

확인되지 않은 지원금·효과·가격은 단정하지 않는다. 상품을 팔기 위해 문제를 과장하지 않는다.
