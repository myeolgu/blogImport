# SEO 및 배포 운영

1. 모든 공개 페이지에 고유한 제목, 설명, canonical URL을 둔다.
2. 새 도구 페이지는 sitemap에 포함되는지 확인한다.
3. robots.txt가 크롤링을 막지 않는지 확인한다.
4. 도구 상세 페이지의 SoftwareApplication JSON-LD를 실제 데이터와 일치시킨다.
5. 홈, 카테고리, 상세 페이지가 서로 링크되도록 내부 링크를 추가한다.
6. 배포 후 공개 URL에서 홈, sitemap, robots, 대표 상세 페이지를 HTTP 200으로 확인한다.

검색엔진 등록은 코드만으로 끝나지 않는다. 소유권 인증 후 Search Console에 sitemap URL을 제출해야 한다.
